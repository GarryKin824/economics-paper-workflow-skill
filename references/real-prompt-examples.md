# 实际派发给子对话的 Prompt｜脱敏原文

这里收录项目协调者**实际发给各子对话执行**的任务指令。内容来自真实派发记录，保留任务、输入、执行边界和交付要求。它们是供选择的参考样例，与各步骤的通用模板分开。本文件不把用户对协调者的请求、拟供用户转发的草稿或事后重写的提示词当成派发原文。

方括号及全角方括号标记替换或整块隐去的原内容，例如项目身份、私有文件标识、路径、未公开数据、可识别匿名稿的研究细节以及随附的私人交流。公开 Skill 的名称、版本及固定提交可保留。每条指令只服务于当时的阶段；在新项目中请替换材料和约束，不沿用当时的授权、日期、模型、旧项目资料或结论。首次调用时由 Skill 询问是否要重点参考这份样例。

## 01｜选题筛选

**实际接收方：选题对话**

~~~text
继续[赛事及届次]个人投稿的前期选题。[作者] 要求按他发来的[学校]实证论文框架重新筛选：前沿只是入口，推荐题必须能完成有机制、有真实数据、有可信识别的经济学论文。此前 [候选题]降为待验证候选，[未公开算例数值] 仅为条件性费率算例；如果拿不到[候选题待验证的关键变量]，不列主选。勿复用[其他未公开项目]成果。稿件至少 6000 字，通知写 [官方截止日期]，请倒推个人可完成的时间。当前只负责选题论证，不替 [作者] 定题或启动主体写作。

先从近两年有真实制度变化、交易规则变化或新公开数据的现象找题，范围不局限 AI/Token。结合成熟经济学机制，优先寻找能解释反直觉行为或区分两种竞争机制的问题。查读最近且最接近的原始研究（包括工作论文）和制度/数据原件；具体写已有论文做了什么、我们在哪个问题、样本或识别上增加了什么。优先有公开、被授权且今天可取得的数据；不要承诺未确认的付费、私有或需审批的数据，不编造结果或文献。

请制作新一轮选题比较与可行性记录，给出 1 个主推、1 个可执行备选；可先广筛，但达不到硬条件的题列为淘汰并说明卡点，不凑数。对每个入围题按截图的顺序填实：
1. 题目、经济现象、具体研究问题、贡献；样本单位、观察频率、样本期，核心 X/Y、控制变量、机制变量逐一写清定义、指标计算、字段名、数据源及文献依据；禁止把处理后的变量当作基准控制项。
2. 写可证伪的 H1/H2，讲清为什么经济机制会产生这个结果，以及什么结果会推翻解释。机制指标须可观察，至少提出一个能区分主机制与替代解释的检验。
3. 写基准模型、估计量、对照组与模型逻辑；单列内生性威胁、识别所依赖的假设和可做的证伪检验、稳健性以及有理论预期的异质性。不要因模板而硬套 DID/IV/中介回归；已有数据不支持因果就诚实说明，不能包装成因果题。
4. 做最小数据探查：实际打开或下载代表性公开样本，核对关键列、可连接键、覆盖期和处理/对照是否有足够变化；能快速做就给可复现的小样本描述统计、图或匹配率，不预设显著结论。区分已查实与仍假定，注明文件、链接和运行办法。不花费额度或绕过访问限制。
5. 按比赛的创新、文献、方法、实证逻辑和启示五项比较候选；给出推荐顺序、预计完工时间、第一张结果表能否做、最可能失败的地方及何时应淘汰。交付一份可审阅的 Markdown 及相应数据探查产物，并在完成回复中给出落点。若 Windows 不可用但还能在当前环境利用公开资料，先推进能独立完成的部分。
~~~
